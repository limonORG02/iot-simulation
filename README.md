### Описание проекта

Этот проект представляет собой простую симуляцию IoT-системы на языке C++, состоящей из:

датчика температуры (виртуальный, генерирует значения),

анализа полученных данных,

принятия решения об управлении “актуатором”:
— включить вентилятор
— включить обогреватель
— ничего не делать

Программа полезна для учебных работ по IoT, C++, моделированию датчиков и базовой обработке данных.

### Функциональность программы
✔ Генерирует 10 измерений температуры

Температура случайная: от –10°C до +30°C.

✔ Анализирует данные

среднее значение;

минимум;

максимум.

✔ Управляет «актуатором»

На основе средней температуры:

Средняя температура	Действие
> 25°C	Включить вентилятор
< 5°C	Включить обогреватель
5–25°C	Ничего не делать

## Запуск и сборка

🔷 1. Требования

Компилятор C++:

Linux: g++ (GNU GCC)

Windows: MinGW / MSVC / OpenWatcom / CLang

Поддержка стандарта C++11+

🚀 Сборка и запуск
🐧 Linux
🔨 Установка компилятора

Ubuntu / Debian:

sudo apt update
sudo apt install g++

🔧 Сборка
g++ src/main.cpp -o iot

▶ Запуск
./iot

---




🪟 Windows
🔨 Вариант 1: через MinGW

Установить MinGW (g++)

Добавить путь к bin в переменную PATH

🔧 Сборка
g++ src\main.cpp -o iot.exe

▶ Запуск
iot.exe

🔨 Вариант 2: через Visual Studio Developer Command Prompt
cl src\main.cpp
main.exe
